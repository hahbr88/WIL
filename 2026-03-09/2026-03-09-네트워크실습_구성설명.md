# 1️⃣ 네트워크 개요 (Topology)

먼저 토폴로지를 보여준다.

발표 멘트 예시

> XXX IT Global은 본사, 데이터센터, 지사로 구성된 기업 네트워크이며 Internet Router를 중심으로 각 네트워크가 연결된 WAN 구조로 설계했습니다.

구조

```
Internet Router
   │
   ├ HQ
   ├ RC (Research Center)
   ├ BB (Busan Branch)
   ├ GB (Gwangju Branch)
   └ DataCenter
```

설명 포인트

* **Hub-and-Spoke WAN topology**
* WAN 연결 방식: **PPP Serial**
* Internet Router가 **WAN 허브 역할**

# 2️⃣ IP Address 설계

다음으로 **Subnet Table 시트** 보여주기

네트워크를 영역별로 나눔

| 영역          | Network                 |
| ----------- | ----------------------- |
| HQ VLAN     | 10.10.10.0 ~ 10.10.40.0 |
| Branch VLAN | 10.10.50.0 / 10.10.60.0 |
| WAN         | 100.100.x.x             |
| DataCenter  | 108.89.11.0             |

설계 포인트

WAN

```
/30
```

이유

> Point-to-Point 링크이기 때문에 /30 서브넷을 사용했습니다.

LAN

```
/24
```

Branch LAN

```
/25 /26
```

# 3️⃣ HQ 네트워크 구조 (VLAN)

HQ는 부서별 네트워크 분리

| VLAN | Network    | 용도      |
| ---- | ---------- | ------- |
| 10   | 10.10.10.0 | DEV     |
| 20   | 10.10.20.0 | DESIGN  |
| 30   | 10.10.30.0 | HR      |
| 40   | 10.10.40.0 | ACCOUNT |

설명

> HQ Router에서 Router-on-a-Stick 방식으로 Inter-VLAN Routing을 구현했습니다.

HQ Router 인터페이스

```
Fa0/1.10
Fa0/1.20
Fa0/1.30
Fa0/1.40
```

# 6️⃣ 라우팅 설계

네트워크 라우팅 방식

```
Hybrid Routing
```

| Router | Routing |
| ------ | ------- |
| HQ     | RIP     |
| RC     | RIP     |
| BB     | RIP     |
| DC     | Static  |
| GB     | Static  |

설명

> 내부 네트워크는 RIP을 통해 자동으로 경로를 교환하고 일부 네트워크는 Static Route를 사용했습니다.

---

# 7️⃣ 설계 포인트 (보안 라우팅 정책) ⭐

여기서 **가장 중요한 설계 포인트 설명**

발표 멘트

> 데이터센터 네트워크는 보안을 위해 RIP에 광고하지 않고 정적 라우트를 통해 연구소와의 통신만 허용하도록 설계했습니다.

구조

```
Research (192.168.91.0)
        │
      RC Router
        │
   Internet Router
        │
     DC Router
        │
 DataCenter (108.89.11.0)
```

설명

* DataCenter 네트워크는 **RIP에 광고하지 않음**
* Static Route로만 경로 설정
* 따라서

```
Research ↔ DataCenter
```

만 통신 가능

다른 지사는

```
경로 없음
```

# 8️⃣ 구현 방법

설정 예시

DC Router

```
ip route 192.168.91.0 255.255.255.192 100.100.103.1
```

Internet Router

```
ip route 108.89.11.0 255.255.255.0 100.100.103.2
ip route 192.168.91.0 255.255.255.192 100.100.102.2
```

RC Router

```
ip route 0.0.0.0 0.0.0.0 100.100.102.1
```

핵심

```
RIP에 광고하지 않음
```
