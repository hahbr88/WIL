### 1. 호스트가 속한 네트워크/브로드캐스트 구하기

10.20.30.40 /12 호스트가 속한 네트워크 주소와 브로드캐스트 주소  

```bash

일단 A클레스

A 클래스 주소 대역을 /12로 서브넷팅한것

/12 는 
첫 8비트 = 고정
다음 4비트 = 네트워크
나머지 20비트 = 호스트

이걸 이진수로 생각해보면

11111111.11110000.00000000.00000000

  128
   64
   32
+  16  
  240

따라서 서브넷 마스크는 255.240.0.0


네트워크 범위는 

256-240 = 16

따라서 각 블록의 크기는 16

그럼 2번째 옥텟 20은 어디에 들어가나?

16~31에 들어간다

따라서 네트워크 주소는 10.16.0.0

그럼 브로드캐스트 주소는 10.31.255.255

```

(1) 서브넷 마스크 = 255.240.0.0  
(2) 네트워크 주소 = 10.16.0.0
(3) 브로드캐스트 주소 = 10.31.255.255

10.200.15.99 /13 호스트가 속한 네트워크 주소와 브로드캐스트 주소

```bash
A 클래스 주소 대역을 /13으로 서브넷팅

11111111.11111000.00000000.00000000

서브넷마스크 255.248.0.0

256-248 = 8

떠라서 블록 8개씩

각 범위는 8/16/24/32/40/48/56/64/72/80/88...  200/208/216/224/232/240/248

```

10.64.250.1 /11 호스트가 속한 네트워크 주소와 브로드캐스트 주소

```bash
A 클래스 주소를 /11 로 서브넷팅 한것

11111111.11100000.00000000.00000000

추가된 3비트가 서브넷을 나눈다 따라서 2^3 = 8개가 서브넷팅 갯수가 된다 (이건 그냥 해봄)

서브넷마스크는 255.224.0.0

256-224 = 32 따라서 블록은 32개씩 

네트워크 시작값은

(해당 옥텟 값 // 블록크기) × 블록크기 

로 쉽게 구할수 있는데 

따라서 (64/32) * 32 =  64 <- 네트워크 시작값

네트워크 주소는 10.64.0.0
브로드캐스트 주소는 10.95.255.255
```

(1) 서브넷 마스크 = 255.224.0.0
(2) 네트워크 주소 = 10.64.0.0
(3) 브로드캐스트 주소 = 10.95.255.255
