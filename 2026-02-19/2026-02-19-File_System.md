# 2026-02-19-File_System

## 1. 파일 시스템(File System)의 정의

파일 시스템은 컴퓨터에서 **데이터를 기록하고 관리하는 규칙의 집합**입니다.

사용자가 작성한 문서나 사진 같은 데이터는 하드디스크(HDD)나 SSD 내부에서는 단순히 **0과 1의 비트(Bit) 덩어리**일 뿐입니다. 파일 시스템은 이 무질서한 비트들을 우리가 알아볼 수 있는 '파일'이라는 단위로 묶어주고, 계층적인 '폴더' 구조로 배치하여 체계적으로 관리할 수 있게 돕습니다.

---

## 2. 창고 비유로 본 파일 시스템의 핵심 기능

거대한 창고(저장장치)에 물건(데이터)을 들여놓는 과정에 비유하면 파일 시스템의 역할을 더 쉽게 이해할 수 있습니다.

| 단계 | 역할 | 상세 설명 (Technical Insight) |
| ------ | --- | ------ |
| **데이터 쌓기** | **공간 할당** | 데이터를 섹터(Sector)나 블록(Block) 단위로 쪼개어 빈 공간에 효율적으로 배치합니다. |
| **이름표 붙이기** | **메타데이터 관리** | 파일명뿐만 아니라 생성 날짜, 수정 시간, 파일 크기, 읽기/쓰기 권한 등의 정보를 기록합니다. |
| **위치 찾기** | **인덱싱(Indexing)** | 파일이 저장된 물리적 주소를 기록한 '주소록'을 관리하여 사용자가 호출 시 즉시 찾아냅니다. |

---

## 3. 파일 시스템이 중요한 이유: 데이터의 지도

파일 시스템은 운영체제(OS)와 저장장치 사이의 **'번역가'이자 '지도'** 역할을 합니다.

* **빠른 검색:** 인덱스(Index)라는 색인 표가 있어, 수 테라바이트(TB)의 데이터 중에서도 원하는 파일을 수 밀리초(ms) 안에 찾아낼 수 있습니다.
* **데이터 보호:** 갑작스러운 전원 차단 시 데이터가 깨지지 않도록 기록 내역을 미리 저장하는 '저널링(Journaling)' 기능을 수행합니다.
* **효율적 공간 활용:** 큰 파일을 조각내어 빈 공간 곳곳에 채워 넣음으로써 저장 공간의 낭비를 최소화합니다.

---

## 4. 실생활에서 접하는 파일 시스템의 종류

운영체제마다 사용하는 '관리 규칙'이 다르기 때문에, 어떤 파일 시스템을 쓰느냐에 따라 호환성이 달라집니다.

* **NTFS (New Technology File System):** 윈도우의 표준 방식입니다. 보안이 뛰어나고 대용량 처리에 적합하지만, 맥(macOS)에서는 읽기만 가능하고 쓰기가 제한되는 등 호환성 제약이 있습니다.
* **APFS (Apple File System):** 최신 맥과 아이폰에 최적화된 방식입니다. SSD 환경에서 매우 빠르고 복사 속도가 혁신적입니다.
* **FAT32 / exFAT:** USB 메모리나 SD카드에서 흔히 씁니다. '범용성'이 최고라 윈도우, 맥, 안드로이드 어디서든 읽고 쓸 수 있습니다. (단, FAT32는 파일 한 개당 4GB가 넘으면 담지 못한다는 단점이 있어 최근엔 **exFAT**을 주로 씁니다.)

---

> 파일 시스템은 마치 **'보이지 않는 사서'**와 같습니다. 우리가 '내 PC'를 열어 파일을 더블 클릭할 때, 그 사서는 눈 깜빡할 사이 거대한 창고를 달려가 정확한 책을 꺼내오는 셈
