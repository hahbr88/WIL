# 2026-02-19-TCP

## ✅ TCP란?

**TCP**
→ 신뢰성 있는 연결형 전송 프로토콜

📍 계층: 전송 계층 (Transport Layer)  
📍 목적: 데이터를 **정확하고 순서대로** 전달

---

## 🔥 TCP의 핵심 특징 5가지

### 1️⃣ 연결형 (Connection-Oriented)

데이터 보내기 전에 반드시

👉 **3-way handshake** 수행

```bash
SYN → SYN+ACK → ACK
```

연결이 성립되어야 통신 시작.

---

### 2️⃣ 신뢰성 보장 (Reliable)

TCP는 이런 걸 다 해줌:

✔ 손실 감지
✔ 재전송
✔ 순서 보장
✔ 중복 제거

UDP는 이런 거 안 함 😄

---

### 3️⃣ 순서 보장 (Sequence Number)

모든 바이트에 번호를 붙임.

예:

```bash
1000 ~ 1499
1500 ~ 1999
```

만약 1500이 먼저 오고 1000이 나중에 와도
→ TCP가 순서 맞춰서 재조립

---

### 4️⃣ 흐름 제어 (Flow Control)

수신자가 감당 가능한 만큼만 보내게 함.

→ Window Size 사용

수신자:

> “나 지금 5000바이트까지 받을 수 있어”

---

### 5️⃣ 혼잡 제어 (Congestion Control)

네트워크가 막히면 속도 줄임.

대표 알고리즘:

* Slow Start
* Congestion Avoidance

👉 이게 인터넷을 안정적으로 유지시켜 줌.

---

## 📦 TCP 헤더 구조 (중요!)

최소 20바이트

```bash
Source Port
Destination Port
Sequence Number
Acknowledgment Number
Flags (SYN, ACK, FIN, RST 등)
Window Size
Checksum
```

시험에서 자주 나오는 플래그:

|플래그|의미|
|---|-----|
|SYN|연결 시작|
|ACK|확인|
|FIN|연결 종료|
|RST|강제 종료|
