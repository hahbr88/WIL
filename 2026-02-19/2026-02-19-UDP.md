# 2026-02-19-UDP

## ✅ UDP란?

**UDP**
→ 전송 계층(Transport Layer)에 속하는 **비연결형 프로토콜**

✔ 빠름  
✔ 가볍다  
❌ 신뢰성 보장 안 함  
❌ 순서 보장 안 함  

---

## 🔥 UDP의 핵심 특징

### 1️⃣ 연결을 맺지 않는다 (비연결형)

TCP는 3-way handshake를 하지만
UDP는 **바로 전송**한다.

👉 “보낸다 → 끝”

---

### 2️⃣ 신뢰성 없음

* 도착했는지 확인 안 함
* 재전송 없음
* 순서 보장 없음

그래서 가볍고 빠름.

---

### 3️⃣ 오버헤드가 작다

#### UDP 헤더 구조 (8바이트)

```bash
[ Source Port ] 2B
[ Dest Port   ] 2B
[ Length      ] 2B
[ Checksum    ] 2B
```

👉 TCP는 20바이트 이상
👉 UDP는 8바이트 → 빠른 이유

---

## 📦 언제 UDP를 쓸까?

### 🎮 실시간 서비스

* 온라인 게임
* 화상통화
* 스트리밍

조금 손실돼도 **속도가 더 중요**할 때 사용.

예:

* **DNS**
* VoIP
* 실시간 방송

---

## ⚡ TCP vs UDP 비교

|구분|TCP|UDP|
|-----|-------|--------|
|연결 방식|연결형|비연결형|
|신뢰성|보장|없음|
|속도|느림|빠름|
|순서 보장|O|X|
|재전송|O|X|
|용도|웹, 파일전송|게임, 스트리밍|

---

## 🎯 쉽게 비유하면

📦 TCP = 등기 우편
→ 받았는지 확인하고, 분실 시 재전송

📮 UDP = 일반 엽서
→ 그냥 보낸다. 빠르다. 확인 안 한다.

---

## 🔎 그럼 UDP는 왜 필요한가?

“조금 틀려도 괜찮고, 끊기면 안 되는 상황”에서 필요함.

예를 들어:

* 게임에서 위치 좌표
* 음성 통화

👉 1초 전 데이터가 늦게 도착하는 건 의미가 없음
👉 그냥 최신 데이터가 중요
