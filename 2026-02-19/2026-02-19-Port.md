# 2026-02-19-Port

## 🔢 포트(Port)란?

IP 주소가 **어떤 컴퓨터인지**를 구분한다면,
포트 번호는 그 컴퓨터 안에서 **어떤 프로그램(서비스)인지**를 구분.

👉 즉,
**IP = 집 주소**
**Port = 집 안의 방 번호**

예:

```bash
192.168.0.10:80
```

* 192.168.0.10 → 서버
* 80 → 웹 서버 프로그램

---

## 📌 포트 번호 범위

포트 번호는 **0 ~ 65535 (16비트)** 범위.

이걸 크게 3가지로 나눈다.

|구분|범위|특징|
|-----------------------|-------------|-----------|
|Well-Known Ports|0 ~ 1023|표준 서비스용|
|Registered Ports|1024 ~ 49151|일반 프로그램 등록용|
|Dynamic / Private Ports|49152 ~ 65535|임시 포트|

---

### 🏆 1️⃣ Well-Known Ports (잘 알려진 포트)

범위: **0 ~ 1023**

* 국제 인터넷 표준 기관인 Internet Assigned Numbers Authority(IANA)가 공식 지정
* 표준 프로토콜이 사용하는 포트
* 보통 서버 서비스용

#### 대표적인 포트

|포트|프로토콜|설명|
|-----|------|------------|
|20/21|FTP|파일 전송|
|22|SSH|원격 접속|
|23|Telnet|원격 접속(보안 취약)|
|25|SMTP|메일 전송|
|53|DNS|도메인 변환|
|80|HTTP|웹|
|443|HTTPS|보안 웹|

👉 예를 들어,
브라우저에서 `https://` 입력하면 기본적으로 **443번 포트**로 접속한다.

---

### 📦 2️⃣ Registered Ports

범위: **1024 ~ 49151**

* 기업이나 애플리케이션이 IANA에 등록해서 사용
* 꼭 표준은 아니지만 공식 등록 가능

예:

* 3306 → MySQL
* 8080 → 대체 HTTP 서버
* 1521 → Oracle DB

---

### ⚡ 3️⃣ Dynamic / Private Ports (임시 포트)

범위: **49152 ~ 65535**

* 클라이언트가 임시로 자동 할당 받는 포트
* Ephemeral Port 라고도 부른다

예시 상황:

1. 내 PC가 웹 서버(80번) 접속
2. 서버는 80번 사용
3. 내 PC는 52341 같은 임시 포트를 사용

```bash
내PC:52341  →  서버:80
```

👉 통신 끝나면 이 포트는 사라짐

---

### 💡 왜 1024 이하 포트는 특별할까?

리눅스/유닉스 계열에서는
**1024 미만 포트는 관리자(root) 권한 필요**

왜냐면:

* 표준 서비스 보호
* 보안 강화를 위해

그래서 일반 프로그램은 보통 1024 이상을 쓴다.
