# 2026-02-24-DiskPart

아래는 질문에 나온 **DiskPart 명령어 정리**입니다. 기능별로 구분해 설명드리겠습니다.

---

## 1️⃣ 디스크/볼륨 조회 명령어

### 🔹 `list disk`

* 시스템에 연결된 **물리 디스크 목록** 출력
* 상태(온라인/오프라인), 크기, GPT 여부 확인 가능

예시 출력 항목:

* 상태
* 크기
* 사용 가능 공간
* Dyn (동적 디스크 여부)
* Gpt (GPT 파티션 여부)

---

### 🔹 `list volume`

* 생성된 **볼륨(파티션) 목록** 출력
* 드라이브 문자, 파일 시스템, 크기 확인 가능

확인 가능한 정보:

* Ltr (드라이브 문자)
* Fs (파일 시스템: NTFS, FAT32 등)
* 상태
* 시스템/부팅 여부

---

### 🔹 `san`

* 현재 SAN 정책 확인
* 예시 결과:

  ```ps
  SAN 정책: 공유 디스크만 오프라인
  ```

* 서버 환경에서 자동 오프라인 처리 여부 확인할 때 사용

---

## 2️⃣ 디스크 선택 및 상태 변경

### 🔹 `select disk n`

* 작업 대상 디스크 선택
* 예:

  ```ps
  select disk 1
  ```

---

### 🔹 `online disk`

* 오프라인 상태 디스크를 온라인으로 전환

---

### 🔹 `offline disk`

* 선택한 디스크를 오프라인으로 전환

---

### 🔹 `attributes disk clear readonly`

* 디스크의 **읽기 전용(Write Protect) 속성 제거**
* GPT 변환 실패 시 자주 사용하는 명령

---

## 3️⃣ 파티션 스타일 변환

### 🔹 `convert gpt`

* 선택된 디스크를 **GPT 방식으로 변환**
* 기존 파티션이 있으면 오류 발생 가능
* 읽기 전용이면 변환 불가

※ GPT 여부는 `list disk`에서 `*` 표시로 확인 가능

---

## 4️⃣ 파티션 생성

### 🔹 `create partition primary`

* 기본 파티션 생성
* 디스크의 사용 가능한 공간에 생성됨

---

## 5️⃣ 포맷

### 🔹 `format fs=ntfs quick label="이름"`

* 파일 시스템 생성
* `fs=ntfs` → NTFS 파일 시스템
* `quick` → 빠른 포맷
* `label=` → 볼륨 이름 지정

예:

```ps
format fs=ntfs quick label="Date_E"
```

---

## 6️⃣ 드라이브 문자 할당

### 🔹 `assign letter=E`

* 생성한 볼륨에 드라이브 문자 지정

---

## 🔎 전체 작업 흐름 정리

실습에서 수행한 순서는 다음과 같습니다:

1. 디스크 확인 (`list disk`)
2. 디스크 선택 (`select disk`)
3. 오프라인/온라인 변경
4. 읽기전용 해제 (`attributes disk clear readonly`)
5. GPT 변환 (`convert gpt`)
6. 파티션 생성 (`create partition primary`)
7. 포맷 (`format`)
8. 드라이브 문자 할당 (`assign`)
9. 볼륨 확인 (`list volume`)

---
