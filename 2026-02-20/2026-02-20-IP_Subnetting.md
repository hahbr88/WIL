# 2026-02-20-IP_Subnetting

## 1. 개념 정의

**IP Subnetting(서브네팅)** 은
하나의 IP 네트워크를 **여러 개의 작은 네트워크(Subnet)** 로 나누는 기술이다.

기본 목적은 다음과 같다:

- 브로드캐스트 도메인 분리
- IP 주소 공간 효율적 사용
- 네트워크 트래픽 감소
- 보안 및 관리 편의성 향상

---

## 2. 왜 필요한가?

예를 들어:

- 네트워크: `192.168.0.0/16`
- 전체 호스트 수: 65,536개

이를 하나의 네트워크로 사용하면:

- 브로드캐스트 트래픽 과다
- 부서별 분리 불가
- 장애 영향 범위 확대

따라서 부서별로 나누는 것이 합리적이다.

---

## 3. 기본 구성 요소

### ① IP 주소 구조 (IPv4 기준)

IPv4는 32비트 구조:

```bash
Network 부분 | Host 부분
```

이를 구분하는 것이 **Subnet Mask**이다.

|CIDR|Subnet Mask|
|----|---------------|
|/24|255.255.255.0|
|/25|255.255.255.128|
|/26|255.255.255.192|
|/27|255.255.255.224|
|/28|255.255.255.240|

---

## 4. CIDR 표기법

CIDR(Classless Inter-Domain Routing)은
IP 뒤에 `/숫자` 형태로 표기한다.

예:

```bash
192.168.1.0/24
```

의미:

- 앞 24비트 → 네트워크
- 뒤 8비트 → 호스트

---

## 5. 서브네팅 계산 원리

### 공식

- 전체 주소 개수
  <!-- - $n=32-\text{prefix}$ -->
  - $2^\text{(호스트 비트 수)}$ = $2^{(32-\text{prefix})}$

- 사용 가능 호스트 수 = $2^n - 2$

  - 네트워크 주소 1개
  - 브로드캐스트 주소 1개 제외

---

### 예제 1: /24 네트워크

```bash
192.168.1.0/24
```

- 호스트 비트 = 8
- 전체 주소 = $2^8$ = 256
- 사용 가능 = $2^8-2$ 254

범위:

- Network: 192.168.1.0
- First Host: 192.168.1.1
- Last Host: 192.168.1.254
- Broadcast: 192.168.1.255

---

### 예제 2: /26 으로 분할

```bash
192.168.1.0/24 → /26으로 분할
```

`/26` = $2^{(32-26)}=2^6=$  64개씩 분할

- 서브넷마스크: 255.255.255.192  (256-64=192)
- 서브넷 개수: $2^{(26-24)}=2^2$ = 4개

결과:

|Subnet|Host Range|Network 주소|Broadcast 주소|
|----------------|-----------|---------|--------|
|192.168.1.0/26|.1 ~ .62|.0|.63|
|192.168.1.64/26|.65 ~ .126|.64|.127|
|192.168.1.128/26|.129 ~ .190|.128|.191|
|192.168.1.192/26|.193 ~ .254|.192|.255|

## 6. 서브네팅의 핵심 개념 정리

### ① Borrowing Bits

Host 비트를 Network로 가져오는 것.

예:

`/24 → /27` => 3비트를 빌림.
`/24 → /26` => 2비트를 빌림.

---

### ② Block Size 계산법

```bash
256 - 서브넷마스크 값
```

예:

```bash
/26 → 255.255.255.192
256 - 192 = 64
```

64 단위로 증가.

---

## 7. 클래스 기반 vs 클래스리스

### 클래스 기반 (과거)

- A class → /8
- B class → /16
- C class → /24

### 클래스리스 (현재 표준)

- IETF에서 정의한 CIDR 방식
- 클래스 구분 없이 유연하게 분할

---

## 8. 실무에서 중요한 포인트

### ① VLSM (Variable Length Subnet Mask)

서브넷마다 다른 마스크 사용 가능

예:

- 서버: /28
- 사용자: /24
- 포인트투포인트: /30

---

### ② 라우팅과의 관계

- 서브넷은 Layer 3 개념
- 라우터가 서브넷 경계 역할 수행
- 각 서브넷은 별도 브로드캐스트 도메인

---

## 9. 시험/면접 핵심 질문 정리

1. /27 은 몇 개의 호스트?

   - 2⁵ - 2 = 30

2. 255.255.255.224 는 몇 비트?

   - /27

3. 192.168.1.130/26 의 네트워크 주소?

   - 192.168.1.128
